# Сайт артиста — alternative rock

Тёмная элегантность: глубокий чёрно-изумрудный фон, мягкое свечение,
утончённый шрифт с засечками и нежный пыльно-розовый акцент.
Образ — нежность, в которой настоящая сила и боль.

## Как это устроено

Сайт полностью статический — обычные HTML, CSS и JavaScript, без сборки.
Это значит, что он мгновенно публикуется на Netlify и работает очень быстро.

```
index.html        — вся страница и весь текст
css/style.css     — оформление, цвета, анимации
js/main.js        — анимации, меню, эффекты
assets/           — изображения (сюда положи своё фото)
netlify.toml      — настройки публикации
```

## Что нужно заменить (ищи пометки ░░ в index.html)

1. **Имя** — замени все `NAME` на своё сценическое имя.
2. **Слоган** — в секции HERO.
3. **Фото** — положи файл в `assets/portrait.jpg` и в `index.html`
   замени `assets/portrait-placeholder.svg` на `assets/portrait.jpg`.
4. **Текст о себе** — секция «О себе».
5. **Ссылки на музыку** — секция «Музыка», атрибуты `href`.
6. **Плееры** — вставь embed-код (Spotify: трек → Поделиться → Встроить).
7. **Почта и соцсети** — секция «Контакты».

## Локальный просмотр

Просто открой `index.html` в браузере. Либо запусти простой сервер:

```
python3 -m http.server 8000
```

и открой http://localhost:8000

## Публикация на Netlify

Netlify подключён к этому репозиторию — после `git push` сайт обновится сам.
